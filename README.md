# Iteration 2: Generative Content Creation Module

Full implementation of the FYP Iteration 2 -- stress-conditioned real-time horror asset generation with multiple generative models.

## Modules Implemented

### 1. Fusion Generator Model
- Conditional MLP that maps stress level (0-5) + noise to 30 output parameters
- Controls all downstream generators: audio, DSP, visual, camera, camera feed, entity
- ~500K parameters, <1ms inference on GPU
- ONNX export for Unity integration

### 2. Audio Generation Engine
- **WaveGAN**: Lightweight conditional 1D GAN (~2M params) trained on wildlife vocalizations + horror audio
- **DSP Chain**: Real-time effects (pitch shift, distortion, reverb, filtering, layering, panning)
- Generates unique audio stingers per stress level

### 3. Texture Generation / Visual Modification Engine
- Conditional U-Net (~3M params) for texture corruption
- Transforms clean PBR textures into horror variants (blood, grime, cracks, scorch, decay)
- Trained on paired procedurally-corrupted data
- 256x256 output, <5ms inference

### 4. Entity Appearance Generator
- Procedural system with model-driven parameters (morphology, opacity, flicker, movement, eyes, aura)
- Entity presets: shadow_pass, silhouette_stare, hallway_flash, corner_lurk
- Activates at stress levels 4-5

### 5. Peripheral Vision Camera Feed Manipulation
- Live webcam capture with face distortion (uncanny valley warping)
- Edge shadow injection and background darkening
- Gaslighting mechanic: effects stronger at LOW stress, normalizes at HIGH stress

### 6. Asset Download Pipeline
- Fetches PBR textures from AmbientCG (CC0)
- Fetches horror/ambient audio from Freesound API
- Fetches wildlife vocalizations for audio model training
- Organized by stress level with auto-generated catalog

## Quick Start

### Install dependencies
```bash
pip install -r requirements.txt
```

### Download assets (requires Freesound API key)
```bash
python download_assets.py --textures
python download_assets.py --audio --wildlife --freesound-key YOUR_KEY
python download_assets.py --catalog-only
```

### Train models (sequential)
```bash
python train_fusion.py --epochs 40 --batch-size 128
python train_audio_gen.py --epochs 50 --batch-size 32
python train_texture_gen.py --epochs 30 --batch-size 8
```

### Run GUI demo
```bash
python gui_demo.py --model models/fusion_generator.pt
python gui_demo.py --no-camera
```

## Unity Integration (Iteration 3)

All models export to ONNX format compatible with Unity Barracuda/Sentis:
- `fusion_generator.onnx`: stress_level + noise -> 30 parameters
- `audio_generator.onnx`: noise + stress -> 1s audio waveform (16kHz)
- `texture_generator.onnx`: clean_texture + stress -> corrupted_texture (256x256)

Command schema (`src/iteration2/commands.py`) defines the data contract between
the generation system and the Unity game engine.
